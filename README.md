# AI 繪圖提示詞工廠

輸入一句話的中文畫面概念，優化成適合 Google Nano Banana Pro／Gemini、ChatGPT／DALL-E、Midjourney，或不特定模型的通用格式使用的圖片生成提示詞。

🔗 **線上使用**：<https://m255525.github.io/ai-image-prompt-studio/>

⚠️ **需要授權序號才能使用**（見下方「授權序號」一節）。

## 這是什麼

- **共用一組概念與風格欄位**：概念描述、風格（含 4 個以電商銷售為目的的選項）、構圖／視角、光線氛圍、色調／色彩風格（暖色調／黃白調／莫蘭迪色系／黑白單色等，獨立於風格的第二個維度）、長寬比、畫質強化詞、常見負面提示詞（可複選）＋自訂負面提示詞，四個目標模型分頁共用，只需填一次。
- **四個目標模型分頁**：切換分頁只改變「組裝格式」——Gemini／ChatGPT 走自然語言描述句，Midjourney 走逗號分隔關鍵詞＋`--ar --v` 參數語法，通用格式適合大多數圖片生成工具。
- **兩段式輸出**：「🔧 組成提示詞」是純前端關鍵字組裝，不需金鑰、不連網；「🚀 送給 AI 優化」選用，串接你自己的 LLM API，把概念翻譯、擴寫成中英對照的正式提示詞。
- **🔗 從商品網址抓取重點**：貼上商品頁面網址，自動抓取網頁內容並用 AI 整理成商品賣點，帶入「概念描述」，不用自己動手描述商品特色。
- **🎬 五秒影片腳本參考**：AI 優化完成後，可再請 AI 根據優化後的圖片內容，提出 3 個 5 秒鐘動態影片腳本方案（鏡頭運動／動態元素／英文動作提示詞），用於把靜態圖轉成短影音（例如貼給 Kling／Runway／Google Veo 等圖生影片工具）。

## 功能

- **電商導向風格選項**：電商白底商品圖／電商情境生活風／電商平拍陳列／電商促銷海報風，英文提示詞片語本身就帶有「適合線上商店刊登、吸引買家下單」的銷售導向描述
- **常見負面提示詞勾選**：浮水印／模糊失焦／低畫質／變形肢體／雜亂背景／過曝曝光不足／人手入鏡／額外品牌標誌，可複選＋自訂文字補充
- **內建範例**：4 組完全虛構的情境範例，一鍵套用快速上手
- **BYOK**：支援 Claude／OpenAI／Gemini／OpenRouter 四選一，API 金鑰只存在瀏覽器 localStorage，不經過任何後端伺服器
- **已儲存的提示詞**：可將組成的提示詞（連同 AI 優化結果、影片腳本）存成有名字的紀錄，之後載入、複製、下載 .txt 或刪除
- **授權序號閘門**：整個工具需輸入有效序號才能使用，效期 12 個月
- 響應式版面，桌機／平板／手機皆可使用

## 怎麼用

1. 開啟 <https://m255525.github.io/ai-image-prompt-studio/>，輸入授權序號
2. 填「概念描述」，視需要套用範例或勾選風格／構圖／光線／長寬比／畫質強化詞／負面提示詞
3. 選一個目標模型分頁（Gemini／ChatGPT／Midjourney／通用），按「🔧 組成提示詞」取得可複製的關鍵字草稿；或展開「API 連線設定」貼上你自己的金鑰，按「🚀 送給 AI 優化」取得中英對照的正式提示詞
4. AI 優化完成後，可按「🎬 產生五秒影片腳本」再取得 3 個動態影片腳本方案
5. 滿意的結果可在「已儲存的提示詞」取名儲存

詳細操作說明見 [manual.html](https://m255525.github.io/ai-image-prompt-studio/manual.html)。

## 技術架構

純前端單檔工具，**沒有任何建置流程、框架、npm 依賴**：

| 項目 | 做法 |
|---|---|
| 提示詞組裝 | 純前端字串模板，不連網（概念文字本身不翻譯） |
| 商品網址抓取 | 第三方網頁擷取服務 `r.jina.ai`（免金鑰、支援 CORS）把網頁轉純文字，再交給你的 LLM 整理成概念描述 |
| AI 優化／影片腳本 | 瀏覽器直接 `fetch` 你選擇的 LLM 服務商官方 API（無後端代理） |
| 金鑰儲存 | `localStorage`，只在使用者自己的瀏覽器裡 |
| 授權序號驗證 | Google Sheet + Google Apps Script（免費輕量後端），只做序號驗證，不經手提示詞內容 |
| 頂部跑馬燈 | 與工作區其他工具共用同一個公告來源（可選、失敗不影響主功能） |

## 本機開發

不需要任何建置工具或安裝依賴，純靜態檔案：

```bash
git clone https://github.com/M255525/ai-image-prompt-studio.git
cd ai-image-prompt-studio
python -m http.server 8000
```

開啟 `http://localhost:8000`（本機測試序號閘門需先部署自己的 Apps Script 後端，見 `SETUP-授權伺服器設定.md`）。

## 隱私與資料

本 repo 公開的只有程式碼。你填寫的概念與風格設定、組成的提示詞、AI 優化結果、影片腳本只存在自己瀏覽器的 localStorage；按下「送給 AI 優化」或「產生五秒影片腳本」時，這些內容會直接連線送到你選擇的 AI 服務商，不經過本工具作者或任何第三方伺服器。授權序號驗證只會傳送序號本身給驗證伺服器，不會傳送任何提示詞內容。「從商品網址抓取重點」是唯一的例外——網址與網頁內容會先送到第三方網頁擷取服務 `r.jina.ai`，再交給你選擇的 AI 服務商，不想用這項功能可直接手動填寫概念描述。
