一句話概念，組出一份好用的繪圖提示詞

填一次概念與風格，四種目標模型格式共用——組成純關鍵字提示詞不需金鑰，或串接你自己的語言模型，取得中英對照的正式提示詞。

✎概念與風格設定

以下設定四個目標模型分頁共用；只有下方「組成提示詞」的格式規則會依分頁不同。

會嘗試抓取這個網址的網頁內容，並用下方「送給 AI 優化」的 API 連線設定（服務商／模型／金鑰）整理成商品賣點，自動帶入下面的「概念描述」。部分網站可能無法正確抓取（例如需要登入、有阻擋機制、或內容由 JavaScript 動態載入），失敗時請自行複製貼上商品特色文字到概念描述欄位。

▦目標模型

AI送給 AI 優化（中英對照）

串接你自己的語言模型 API，把概念與風格設定送出，取得針對目前分頁模型優化過的正式提示詞——先是一段中文說明供你確認語意，接著是可直接貼給圖片模型使用的英文提示詞。

API 連線設定

金鑰只存在這台電腦的瀏覽器（localStorage），不會送到本工具以外的任何地方；按下「送給 AI 優化」時，概念與風格設定會直接傳送給你選擇的服務商 API。請勿在共用電腦上填寫金鑰。

🎬五秒影片腳本參考（選用）

根據上面「AI 優化結果」的圖片內容，生成 3 個 5 秒鐘的動態影片腳本參考——可用於把這張靜態商品圖轉成短影音的靈感（例如 Kling／Runway／Google Veo 等圖生影片工具的動作提示，或剪輯短影音時的腳本參考）。需要先完成上方「送給 AI 優化」才能使用。

REC已儲存的提示詞

把目前這份提示詞（含 AI 優化結果與五秒影片腳本，若有）存成一筆有名字的紀錄，留在這台瀏覽器裡；需要檔案再從清單裡個別下載。

使用警語
  • 本工具產生的是「圖片生成提示詞」，實際生成的圖片內容與品質仍取決於你使用的圖片模型服務，請自行檢查是否符合該服務的條款與政策。
  • 請勿在任何欄位輸入真實個資、機密資料或受著作權保護的他人內容——欄位資料只存在你自己瀏覽器的 localStorage，不會上傳到任何伺服器，但送出給 AI 服務後的隱私仍由該服務條款規範。
  • 「送給 AI 優化」需要你自行填入 API 金鑰，該金鑰只存在你的瀏覽器，按下產生時會直接連線到你選擇的服務商，本工具不會經手或保存金鑰，也不會向你收取任何 API 費用——實際費用依你與該服務商的方案計算。
  • 「從商品網址抓取重點」會把網址與網頁內容送到第三方網頁擷取服務（r.jina.ai）再交給你選擇的 AI 服務商，請勿用於含機密或個資的網頁；不想使用這項功能可直接手動填寫概念描述。
  • AI 優化結果可能有誤，貼給圖片模型前請自行檢查；本工具與創作者不對後續生成的圖片內容負責。
  • 僅供教學、課程及個人使用，禁止未經授權公開發布、販售或商業化使用。
