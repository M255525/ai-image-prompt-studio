AI 繪圖提示詞工廠
← 回到工具

操作手冊

AI 繪圖提示詞工廠把一句話的畫面概念，優化成適合 Google Nano Banana Pro／Gemini、ChatGPT／DALL-E、Midjourney 或通用格式使用的圖片生成提示詞。填一次概念與風格設定，四個目標模型分頁共用；可以直接複製組成結果，也可以串接你自己的語言模型取得中英對照的正式提示詞。

四個目標模型分頁的差異

GM
Google Nano Banana Pro／Gemini

自然語言描述句為主，1～3 句話即可，不需要任何參數語法，直接貼進 Gemini 或 Nano Banana Pro 的圖片生成對話框。

GPT
ChatGPT／DALL-E

同樣是自然語言描述句，貼給 ChatGPT 的圖片生成功能或 DALL-E 使用，寫法習慣與 Gemini 接近。

MJ
Midjourney

逗號分隔的英文關鍵詞組（不是完整句子），結尾會附上 --ar（長寬比）與 --v（版本）等參數，符合 Midjourney 的提示詞慣例；若有填「不想出現的元素」會加上 --no 參數。

通用
通用（泛用敘述式）

不特定模型的泛用英文描述句，適合大多數圖片生成工具，沒有特定的參數語法。

操作步驟

  1. 先套用一個「範例」快速看懂欄位怎麼填，或直接從空白開始
  2. 在「概念描述」填入你想畫的畫面內容（必填），並視需要勾選風格、構圖／視角、光線氛圍、長寬比、畫質強化詞、常見負面提示詞（可複選，勾完仍可在下方「其他負面提示詞」補充自訂內容）——這些設定四個目標模型分頁共用，只需要填一次
  3. 在最上方選一個目標模型分頁（Gemini／ChatGPT／Midjourney／通用）
  4. 按「🔧 組成提示詞」，下方會出現關鍵字組裝結果，可按「複製提示詞」直接使用
  5. 若想取得正式的中英對照提示詞（概念文字經過翻譯與潤飾），展開「送給 AI 優化」面板的「API 連線設定」填入自己的金鑰，按「🚀 送給 AI 優化」
  6. 滿意的結果可以在下方「已儲存的提示詞」取名儲存，之後隨時載回來或下載成 .txt 檔
切換目標模型分頁不會清掉概念與風格設定——這些欄位是四個分頁共用的；但每個分頁各自的「組成結果」與「AI 優化結果」會分開保留。
「風格」下拉選單裡有四個以電商銷售為目的的選項（電商白底商品圖／電商情境生活風／電商平拍陳列／電商促銷海報風），適合幫網路商店的商品圖、行銷banner找靈感；選了之後組成的提示詞會自然帶入「適合線上商店刊登、吸引買家下單」的描述方向。

「組成提示詞」與「送給 AI 優化」有什麼不同

🔧 組成提示詞是純前端的關鍵字組裝，不需要 API 金鑰、不會連網：把你填的概念文字（保留原始語言）＋風格／構圖／光線／畫質標籤（已經是對應的英文片語）組合成一份草稿，方便快速預覽結構，但概念描述本身不會被翻譯成英文。

🚀 送給 AI 優化會把概念與風格設定送給你設定的語言模型，由 AI 把整段概念翻譯、擴寫並融合風格設定，輸出「先中文說明、再分隔線、最後英文提示詞」的中英對照結果——這才是真正可以直接貼給圖片模型使用的正式提示詞。

如果只是想快速看一下關鍵字組合，用「組成提示詞」就好；真的要拿去生圖，建議走「送給 AI 優化」取得完整翻譯過的英文提示詞。

已儲存的提示詞

「已儲存的提示詞」是一個留在瀏覽器裡的紀錄清單，按「儲存」不會下載任何檔案，只是把目前分頁已組成的提示詞（連同 AI 優化結果，若有）存成一筆有名字的紀錄。

  1. 在儲存名稱欄位打一個好記的名字（留白會自動取名），按「儲存」
  2. 清單中每一筆紀錄可以「載入」（會自動切換回對應的目標模型分頁並覆蓋欄位）、「複製」、「下載 .txt」或「刪除」
  3. 取相同名字再按一次「儲存」會詢問是否要覆蓋既有紀錄
「儲存」＝存進這台瀏覽器的清單；「下載 .txt」才會真的產生一個檔案到你的下載資料夾。兩者是分開的動作。

送給 AI 優化（選用，需自備 API 金鑰）

填好概念與風格設定之後，可以直接在本工具呼叫你自己的語言模型 API，取得針對目前分頁模型優化過的中英對照提示詞。

  1. 展開「API 連線設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter），填入你自己申請的 API 金鑰；模型欄有預設值，也可以自行改成你想用的模型 ID
  2. 按「🚀 送給 AI 優化」
  3. 優化結果會顯示在「AI 優化結果」區塊，可按「複製 AI 結果」使用
API 金鑰要自己到各服務商網站申請，使用時依你與該服務商的方案計費，本工具不會向你收費，也不會經手你的金鑰——金鑰只存在你這台電腦的瀏覽器，且直接連到服務商官方 API，不會經過本工具以外的任何伺服器。

🔑 授權序號

本工具需先輸入授權序號並按「確認」驗證通過，才能使用整個工具（不是只鎖某個功能）。序號自第一次驗證起提供 12 個月使用期限，驗證結果每次開啟頁面都會即時向授權伺服器重新確認，並每 20 分鐘在背景重新驗證一次——序號到期時，畫面會在最多 20 分鐘內自動重新鎖定。

  • 「已逾使用期限」：代表這組序號的 12 個月使用期限已到，請向工具提供者索取新的授權序號

隱私說明

  • 你填寫的概念與風格設定、組成的提示詞與「已儲存的提示詞」清單都只存在自己瀏覽器的 localStorage，關閉分頁後下次打開仍會保留，但不會傳送到任何伺服器；換一台電腦或清除瀏覽器資料就會不見，請自行用「下載 .txt」備份重要內容
  • 複製提示詞後，貼到哪個圖片生成服務、該服務如何處理這些文字，就依該服務自己的隱私政策規範，與本工具無關
  • API 金鑰同樣只存在瀏覽器的 localStorage；按下「送給 AI 優化」時，概念與風格設定會直接連線送到你選擇的服務商官方 API，不會經過本工具作者或任何第三方伺服器
  • 授權序號驗證會把序號本身傳送給授權伺服器（Google Apps Script）比對是否有效，不會傳送你填寫的任何概念或提示詞內容

使用警語

請注意：
  • 本工具的核心功能是把你的畫面概念組織成結構化提示詞；只有你主動填入 API 金鑰並按下「送給 AI 優化」時才會呼叫語言模型，不使用這項功能也能取得關鍵字組裝結果
  • 請勿在任何欄位輸入真實個資、公司機密、他人受著作權保護的內容，或不希望被 AI 服務留存的敏感資訊
  • AI 優化結果可能包含錯誤或不精準的描述，貼給圖片模型前請自行檢查；實際生成的圖片內容與品質仍取決於你使用的圖片生成服務
  • 使用「送給 AI 優化」功能所產生的 API 費用由你與所選服務商的方案自行負擔，本工具不會向你收費
